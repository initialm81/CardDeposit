# 카드입금 (CardDeposit)

매일 오는 `[일별 승인, 취소 리포트]` 문자(기본 발신번호 1599-8898)를 읽어
카드사별 수수료와 입금주기를 적용해 **오늘 입금될 카드대금**과 **월별 캘린더 집계**를 보여주는 안드로이드 앱.

- 문자 읽기 권한(READ_SMS)만 사용, 인터넷 권한 없음 → 문자 내용이 기기 밖으로 나가지 않음
- 화면/계산: `app/src/main/assets/` (index.html, app.js, logic.js)
- 문자함 읽기: `MainActivity.java`

## 설치
`main`에 push하면 GitHub Actions가 APK를 빌드해 `apk` 브랜치에 `CardDeposit.apk`로 올립니다.
폰에서 저장소 → 브랜치 `apk` → `CardDeposit.apk` → 다운로드 후 설치.

## 계산 기준 (설정에서 변경 가능)
- 수수료: 영세·중소가맹점 우대수수료율(신용카드) 0.40 / 1.00 / 1.15 / 1.45%, 일반가맹점 기본 2.2%
- 입금일: 매출일 + 2영업일(우대가맹점), + 3영업일(일반가맹점). 주말·공휴일 제외
